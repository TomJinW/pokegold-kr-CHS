## 剩余的原始字节值（466 个）

| 来源 | 值 | 说明 |
| --- | ---: | --- |
| `data/items/names.asm` 中 `ITEM_BE` 的 `$00` | 426 | 汉化把名称缩短后空出的空间填 `$00`，成为从不显示的 `ITEM_BE` 名称的一部分 |
| 招式语法 0 组的 `$fc` | 29 | 汉化有意停用该组 |
| 条目结束后汉化写入的单个 `$00` | 3 | 单独的 `$00` 是双字节字符的前导字节，不是完整字符 |
| 其他 | 8 | 小霞队伍旧副本的韩文名（CHS 码表中没有这两个码位）、`$d9` 与 `$c7`（单字节中无字符）、湖边小屋未用文本中的 `$00, $5d`（未定义的双字节） |

凡是码表中有字符的字节（含条目结束后留下的零散文本，如 `"哎呀"`、`"　<PROMPT>"`）都已写成字符串。

所有 `0B` 码位都已确认并加入码表（见 `docs/chs.md`）。
